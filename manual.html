1 교안 PDF를 올립니다

주소로 접속한 뒤, 왼쪽 위 네모 칸에 교안 파일을 끌어다 놓습니다. 칸을 클릭해서 골라도 됩니다.

┌─────────────────────────┐ │ 교안 PDF를 끌어다 놓기 │ │ 또는 클릭해서 선택 │ │ .pdf │ └─────────────────────────┘

PDF만 올릴 수 있습니다. PPT 파일을 그대로 올리면 글꼴이 깨지기 때문에 받지 않습니다.

교안이 PPT라면 파워포인트에서 파일 › 내보내기 › PDF 만들기로 저장한 뒤, 그 PDF를 올리세요. 글꼴·도형·차트가 원본 그대로 보존됩니다.

올리면 몇 초 만에 변환되고, 오른쪽에 책이 나타납니다. 모서리를 끌어 넘겨 보세요.

2 차시 번호를 맞춥니다

화면 왼쪽 저장 위치에서 두 칸만 보면 됩니다.

칸넣는 값
주소 경로webcontents/ebook/2026/01 — 한 번 정해지면 그대로 둡니다
진입 파일명01.html — 차시마다 이 숫자만 바꿉니다

1차시는 01.html, 2차시는 02.html, 3차시는 03.html … 이렇게만 바꾸면 됩니다.

바로 아래 회색 상자에 만들어질 주소가 미리 보입니다. 원하는 주소가 맞는지 눈으로 확인하고 넘어가세요.

3 비밀번호를 넣고 저장합니다

웹 저장 칸에 비밀번호 who123을 넣습니다. «비밀번호 기억»이 켜져 있으면 다음부터는 안 넣어도 됩니다.

오른쪽 위 초록 버튼 「웹에 저장하고 링크 만들기」를 누릅니다.

저장소 후미디어 서버 경로 public/webcontents/ebook/2026/01/01.html 용량 12.4 MB 주소 https://www.whomedia.co.kr/webcontents/ebook/2026/01/01 계속할까요? [ 확인 ] [ 취소 ]

확인을 누르면 올라가고, 전달할 주소가 복사 버튼과 함께 나타납니다.

4 주소를 전달합니다

「복사」를 눌러 카카오톡이나 메일에 붙여넣으면 됩니다. 받는 사람은 설치 없이 바로 책을 넘겨 볼 수 있습니다.

알아 두면 좋은 것

여러 차시PDF를 한꺼번에 여러 개 올려 두고, 왼쪽 목록에서 하나씩 골라 저장하면 됩니다.
제목 고치기오른쪽 위 제목을 클릭해 고치면 책 표지와 브라우저 탭 제목이 바뀝니다.
다시 변환「다시 변환」 버튼으로 같은 파일을 새로 변환할 수 있습니다.
보는 방법모서리를 끌거나 화살표로 넘기고, Ctrl+휠 또는 두 손가락으로 확대합니다.
휴대폰가로로 돌리면 자동으로 전체 화면이 되어 크게 보입니다. 화면을 한 번 누르면 위아래 메뉴가 잠깐 나타납니다.
저장 내역「연결 확인」을 누르면 지금까지 올린 교안 목록과 사용 중인 용량이 보입니다.
주의 올린 교안은 주소를 아는 사람이면 누구나 볼 수 있습니다. 대외비 교안은 올리기 전에 관리자와 상의하세요.
